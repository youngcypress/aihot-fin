
【金融领域翻译规则 — 本平台 100% 是财经/资本市场内容，严格遵守】

1. 歧义默认值：以下词在中文有非金融歧义，**一律按金融含义翻译**：
   - Fed = 美联储（绝不译"联邦快递"）
   - FOMC = 美联储议息会议（FOMC 保留）
   - Hawkish / Dovish = 鹰派 / 鸽派
   - Yield = 收益率（绝不译"产量"）
   - Duration = 久期（绝不译"持续时间"）
   - Default = 违约（绝不译"默认"）
   - Short / shorting = 做空 / 空头（语境指交易方向时）
   - Equity = 股票 / 权益（绝不译"公平"）
   - Liquidity = 流动性
   - Credit = 信用（绝不译"学分"）
   - Spread = 利差 / 价差（按语境）
   - Volatility = 波动率
   - Hedge = 对冲
   - Margin = 保证金 / 两融（按语境）
   - Basis point / bp / bps = 个基点（bp 保留英文）
   - RRR = 存款准备金率（"降准"照中文习惯）
   - Taper = 缩减购债
   - Guidance = 前瞻指引
   - Earnings = 财报 / 盈利（按语境）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 机构：Federal Reserve / Fed / ECB / BOJ / IMF / BIS / OPEC / IEA / SEC / FOMC / BlackRock / Vanguard / Bridgewater
   - 指数与品种：S&P 500 / Nasdaq / Dow / Russell 2000 / VIX / WTI / Brent / COMEX / LME / USD / CNY / USDCNH / EUR / JPY
     **规则**：国内指数用中文习惯写法：上证指数、沪深300、中证500、创业板指、恒生指数、恒指、恒生科技
   - 金融缩写（举例 + 通用规则）：GDP / CPI / PPI / PMI / LPR / MLF / SLF / PSL / SLO / IPO / ETF / LOF / QDII / QFII / REITs / FOF / MBS / ABS / CDS / CLO / NPL / MoM / YoY / QoQ / bp
     **规则**：任何 2-5 字母的全大写金融缩写，默认保留英文；MLF/SLF/PSL 等央行工具首次出现可括注中文全称
   - 公司与基金英文名：Goldman Sachs / JPMorgan / Bridgewater / 以及基金、ETF 的英文简称，保留原文

3. 中国机构与市场术语**用官方或习惯中文名**（首次出现可双标，后续保持一致）：
   - 中国人民银行（央行/人行）/ 国家统计局 / 财政部 / 中国证监会（证监会）/ 上交所 / 深交所 / 北交所 / 外汇局 / 交易商协会 / 基金业协会
   - A股术语照习惯写法：涨停、跌停、北向资金、南向资金、两融、打新、抱团、赛道、破净、破发、ST、退市、大小盘、风格切换

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - URL 原样
   - 数字+单位：0.5 个百分点 / 10bp / 1万亿元 / $10B / 99.9% / 30年期
   - 金额、基点、比例、期限必须保留原文的阿拉伯数字和单位；不要把 1 万亿元改写成"约一万亿"，不要把 10bp 改写成"十个基点"以外的近似说法
   - 基金与 ETF 代码一字不改：510300、159915、005827.OF
